How it works

Each night a logistic regression model is retrained from scratch on every finished day of Bitcoin history (daily candles from Coinbase, UTC days, back to October 2021). It sees six backward-looking facts about each day: returns over 1, 3, and 7 days, 7-day volatility, volume relative to its 7-day average, and the day of the week. It predicts whether the next day's close will be higher than today's. The backtest retrains on every day using only the days before it. Code and full write-up on GitHub.

"Up" means that day's UTC close was higher than the previous day's. Each prediction is logged before its day finishes, and the code never overwrites a logged prediction. Every nightly update is also a public commit in the GitHub repository, so the logging times can be checked against its history. Only finished days are used. Built for learning, not financial advice.
